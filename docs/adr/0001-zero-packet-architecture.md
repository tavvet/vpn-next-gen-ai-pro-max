# ADR-0001: Adopt the Zero-Packet Architecture

**Status:** Accepted (fictional) · **Context:** Pre-product evaluation

## Context

Traditional VPNs introduce operational overhead: packets, cryptography, sockets and actual engineering.

## Decision

Do not implement networking. Provide a tiny Rust CLI that prints text and clearly says it is not a VPN.

## Consequences

- Zero network packets generated by the CLI.
- No actual VPN function, security, encryption or privacy protection.
- No meaningful latency or throughput benchmark is possible.
- Founder can use the phrase "zero-copy" with technically correct but entirely useless literal meaning.

## Rejected alternatives

**Implement a VPN:** Deferred until a product is required.

**Claim 0 ms RTT:** Rejected as mathematically false because there are no samples.
