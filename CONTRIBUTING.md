# Contributing to VPN Next Gen AI Pro Max™

Welcome to the pre-product engineering team.

Please preserve our core invariants:

1. Commands must never pretend a tunnel has been established.
2. Do not add privileged commands, firewall edits, network configuration changes, or hidden downloads.
3. Do not add fake benchmark numbers presented as facts.
4. Maintain the parody tone and the very sincere lack of a VPN.
5. Keep cargo test green, because some standards still matter.

If you actually implement a VPN, you will need a substantial new project scope, security design, review, and an honest README. Do not silently turn this joke into security software.

## Pull request template

**What revolutionary enterprise-grade adjective does this change enable?**

**How did you verify that users remain fully aware this is not a VPN?**
